# 2026-10-01 — Stripped the multi-replica machinery

Branch `worktree-single-replica`. Implements ADR-001 in
[`../DECISIONS.md`](../DECISIONS.md).

## Removed

- `internal/cache/redis.go`, `internal/auth/redisstore.go` and their tests; the
  `go-redis` dependency; `cmd/whois-mcp/stores.go` and the
  `WHOIS_MCP_CACHE`, `WHOIS_MCP_SESSION_STORE`, `WHOIS_MCP_REDIS_URL` settings.
- The `/readyz` dependency on a reachable cache backend.
- The denylist's shared-cache path; it is an in-process map.
- The second compose replica and the Redis service.
- The cross-replica steps of `scripts/e2e.sh` and the Redis CI job.
- Chart: `replicaCount`, `autoscaling`, `podDisruptionBudget`,
  `topologySpreadConstraints`, the `redis`, `cache` and `sessionStore` values,
  `hpa.yaml`, the Redis egress rule, the per-replica-sessions and
  signing-key-required guards, and `RUNBOOK_KEY_ROTATION.md`.

## Changed

- The Deployment pins `replicas: 1` with `strategy: Recreate`.
- The signing key is optional end to end: omitted from the Secret when empty,
  read with `optional: true`, generated by the server when absent.
- `scripts/helm-verify.sh` asserts one replica, `Recreate`, no HPA or PDB, an
  optional signing key and no store wiring.
- README, design §11.3 (with the rationale), decision 7, N-2, the config table
  and the plan's status line.

## Verified

`go test -race ./...`, `scripts/helm-verify.sh`, and the compose stack built
locally with `scripts/e2e.sh` run against it.
